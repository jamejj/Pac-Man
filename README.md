# Pac‑Man 👾

Edukacyjna implementacja klasycznej gry Pac‑Man napisana w Javie — lekka gra 2D do nauki logiki gier, kolizji i sterowania.

- Język: Java
- Przeznaczenie: demo / projekt edukacyjny
- Wymagania: JDK 11+

---

Uruchomienie w IDE:
- Otwórz projekt w IntelliJ IDEA/Eclipse.
- Ustaw JDK 11+ i uruchom klasę zawierającą metodę main.
